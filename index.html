Why connect Firebase?

Connecting Firebase Realtime Database enables instant, cloud-based order syncing from customers' phones directly to your admin computer.

  1. Go to Firebase Console and click Create a project.
  2. In the left sidebar, click Build > Realtime Database and click Create Database (start in Test mode).
  3. Go to Project Settings (gear icon) > General > Under Your apps, add a Web app (</>) and copy the firebaseConfig object.
  4. Paste your configuration JSON below and click Save & Connect.
